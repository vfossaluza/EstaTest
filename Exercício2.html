Exercício2

Enunciado

Seja \(X_1, \cdots X_n\) v.a. c.i.i.d tais que

\[ X_i | \lambda \sim Poisson(\lambda) \]

Vamos definir a distribuição a priori para \(\lambda\) como sendo Gama, com parâmetros 2 1, \(\lambda \sim Gama(2, 1)\)

\[ f(\lambda) = \frac{\beta^\alpha}{\Gamma(\alpha)} \lambda^{\alpha-1} e^{-\beta\lambda} \]

com \(\alpha=2, \beta=1\).

Queremos testar

\[ H_0 : \lambda = 3 \quad \text{ contra } \quad H_1 : \lambda \neq 3 \]

Vamos fixar \(n = 5\). A estatística suficiente é: \(T(x) = \sum_{i=1}^{5} X_i\).

Vamos estudar o comportamento das estatísticas de teste para cada valor de \(x \in \{10, 12, 14, 15, 16, 18, 20\}\). As estatísticas de teste são:

(\(i\)) RVG : \[ \lambda (x) = \frac{\displaystyle \sup_{\theta \in \Theta_0} f(x|\theta)}{\displaystyle \sup_{\theta \in \Theta} f(x|\theta)} \]

(\(ii\)) p-value: \[ \sup_{\theta \in \Theta_0} P(X: \lambda(\mathbf{X} \leq \lambda(x)| \theta) \]

(\(iii\)) \(P( \theta \in \Theta_0 | \mathbf{x})\)

(\(iv\)) e-value:

\[ Ev(\Theta_0 | x) = 1 - P(\theta \in T_x | x) \]

Com

\[ T_x = \{ \theta : f(\theta | \mathbf{x} \geq \sup_{\theta \in \Theta_0} f(\theta | x) \} \]

Calculando RVG A RVG compara a verossimilhança máxima restrita à hipótese nula (\(L(\lambda=3)\)) com a verossimilhança máxima irrestrita (\(L(\hat{\lambda})\)).

Com isso, nosso numerador é a verossimilhança em \(\lambda = 3\) e o denominador é a verossimilhança no Estimador de Máxima Verossimilhança (EMV), que para Poisson é a média amostral \(\hat{\lambda} = \bar{X} = T/n\).

A fórmula derivada é:

\[ \Lambda(x) = \frac{e^{-5(3)} 3^T}{e^{-5(T/5)} (T/5)^T} \]

Computacionalmente:

calc_RVG <- function(t, n, lambda0) {
  lambda_hat <- t / n # EMV sob H1
  
  # Log-Verossimilhança sob H0 (lambda = 3)
  ll_H0 <- -n * lambda0 + t * log(lambda0)
  
  # Log-Verossimilhança sob H1 (lambda = t/n)
  if (t == 0) {
    ll_H1 <- 0}
  else {
    ll_H1 <- -n * lambda_hat + t * log(lambda_hat)}

  return(exp(ll_H0 - ll_H1))}

Calculando o p-valor

O p-valor é a probabilidade, sob a hipótese nula (\(H_0\)), de observarmos um dado tão ou mais extremo que o observado. Nesse exemplo, “mais extremo” seria ter uma verossimilhança menor ou igual à observada (não tenho certeza kkk).

Assumimos que \(T \sim Poisson(15)\).

Calculamos a RVG do valor observado (\(rvg_{obs}\)), somamos as probabilidades de todos os valores \(k\) da Poisson que \(rvg(k) \le rvg_{obs}\).

Para fazer isso no R vemos os valores possíveis de uma Poisson(15) (de 0 a 50 cobre quase toda a probabilidade) e somar as probabilidades onde a condição é satisfeita.

calc_pvalue <- function(t_obs, n, lambda0) {
  rvg_obs <- calc_RVG(t_obs, n, lambda0)
  
  # Média é 15, varrer de 0 a 50 é suficiente
  possiveis_k <- 0:50
  prob_total <- 0
  
  for (k in possiveis_k) {
    rvg_k <- calc_RVG(k, n, lambda0)
    
    # Se a verossimilhança de k for "pior" (menor) ou igual à observada
    if (rvg_k <= rvg_obs + 1e-9) { # +1e-9 para evitar erro de ponto flutuante
      prob_total <- prob_total + dpois(k, lambda = n * lambda0)}}
  return(prob_total)}

Calculando o e-valor

Antes disso, precisamos lembrar que a posteriori para a Poisson (com priori Gama) é Gama, com parâmetros \(\alpha \sum x_i\) e \(\beta + n\). Substituindo pelos valores do nosso exercício temos uma \(Gama(2+\sum x_i, 1+5 = 6)\)

Queremos calcular:

\[ \text{e-valor} = 1 - P(\theta \in T(x) | x) \]

A parte computacional estava impossível, tive que usar IA :(

calc_evalue <- function(t, n, lambda0, alpha_pri, beta_pri) {
  # Parâmetros da Posteriori
  alpha_post <- alpha_pri + t
  beta_post <- beta_pri + n
  
  # 1. Densidade no ponto H0 (lambda = 3)
  densidade_ref <- dgamma(lambda0, shape = alpha_post, rate = beta_post)
  
  # Moda da posteriori (pico da curva)
  moda <- (alpha_post - 1) / beta_post
  
  # Se o ponto H0 for exatamente a moda, e-valor = 1
  if (abs(lambda0 - moda) < 1e-4) return(1)
  
  # Função auxiliar para achar onde f(x) = densidade_ref
  f_dif <- function(x) { 
    dgamma(x, shape = alpha_post, rate = beta_post) - densidade_ref 
  }
  
  # 2. Achar os limites do conjunto tangente, precisamos achar duas raízes: uma à esquerda da moda e uma à direita
  tryCatch({
    # Raiz inferior (entre 0 e a moda)
    limite_inf <- uniroot(f_dif, interval = c(0, moda))$root
    
    # Raiz superior (entre a moda e um valor alto, ex: moda + 20 desvios)
    # Usamos moda*3 como um chute seguro para o limite superior de busca
    limite_sup <- uniroot(f_dif, interval = c(moda, moda + 20))$root
    
    # 3. Probabilidade do conjunto tangente (área de alta probabilidade)
    prob_Tx <- pgamma(limite_sup, shape = alpha_post, rate = beta_post) - 
               pgamma(limite_inf, shape = alpha_post, rate = beta_post)
    
    # 4. e-valor é o complemento
    return(1 - prob_Tx)},
    error = function(e) {
    return(0)})} # Se der erro (ex: lambda0 está muito na cauda e ref ~ 0), e-valor ~ 0
